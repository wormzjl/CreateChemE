# Tools of this batch

The code and scripts this batch created for measurement and investigation are kept, runnable and documented, in the main checkout's `tools/` (tooling cleanup of 2026-09-24, review `../2026-09-23-fluid-followups/FLUID_TOOLING_CLEANUP_REVIEW.md`). `tools/fluid-in-game-rig/` holds the WP5 in-game rig; its mod-side measurement log and run switches were detached from the code in `c1b8464` and are re-attached with `mod-side/reattach.patch`. `tools/fluid-paced-analysis/` holds the paced-report scripts (`wp2cmp.js`, `wp2diverge.js`, `wp2evidence.js`, `wp2tables.js`, `wp3tables.js`, `wp3viewers.js`, `wp4savetime.js`, `winlen.js`). `tools/fluid-probes/wp0/`, `wp2/`, `wp3/` and `wp4/` hold the probes, one-off edit scripts and campaign and gate scripts. `tools/mcp-gui-helpers/` holds the WP3 and WP4 dev-client helpers (`Field`, `field.ps1`, `Flatten`, `Stack`). The copies under `wp0-reference/`, `wp2-probes/`, `wp*-logs/` and `wp5-rig/` in this folder are the evidence snapshots the reviews cite; do not run them from here.
