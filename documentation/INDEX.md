# Documentation index

One folder per batch of work, named `YYYY-MM-DD-topic` after the date the batch started. The status column is the batch's current state; update it (with the date) whenever a task in the batch finishes, merges, stalls or is dropped. Layout and update rule: [README.md](README.md). Research data and harnesses: [../research/INDEX.md](../research/INDEX.md). Tools: [../tools/INDEX.md](../tools/INDEX.md). Release history: `CHANGELOG.md` in the repository root.

Status words:

- **Implemented YYYY-MM-DD**: the code is on `main`; the date is the day it reached `main`.
- **In progress since YYYY-MM-DD**: work has started on a branch and has not merged.
- **Planned**: a plan exists and no implementation has started.
- **Concluded YYYY-MM-DD**: research or measurement that was finished and was never meant to change code.
- **Abandoned YYYY-MM-DD** / **Superseded YYYY-MM-DD by ...**: stopped, with the reason.
