# Tools of this batch

The code and scripts this batch created for measurement and investigation are kept, runnable and documented, in the main checkout's `tools/` (tooling cleanup of 2026-09-24, review `FLUID_TOOLING_CLEANUP_REVIEW.md` in this folder). `tools/fluid-in-game-rig/` is the canonical in-game rig, built from `f2-rig/` plus what `f1-rig/` added; the mod-side measurement log detached from the code in `c1b8464` is in `mod-side/` with its re-attach patch. `tools/fluid-probes/f1/`, `f2/`, `f3/` and `f4/` hold the probes (`probes/`, `f*-logs/probes/`), trace and timing instrumentation patches, scripts, NIST data and gate, paced and probe run scripts; the F3 per-section byte hook detached in `68d8877` is `f3/instrumentation/payload-breakdown-hook.patch`. `tools/fluid-paced-analysis/` holds the `wp2cmp.js` and `wp2diverge.js` comparisons F1 reused. `tools/retired/fluid-profile-replays/` holds the dead `fluidStressProfile` and `fluidModuleProfile` replays retired in `68d8877`. The copies under `probes/`, `f*-logs/` and `f*-rig/` in this folder are the evidence snapshots the reviews cite; do not run them from here.
