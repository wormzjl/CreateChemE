# Independent liquid compression references

## Hydraulic references

`hydraulic-friction.json` is generated by `examples/Generate-Hydraulic-References.py` using Python Decimal at 60-digit precision, without production Java calls. It specifies Poiseuille friction below Reynolds 2,000, the project's cubic smoothstep blend from 2,000 to 4,000, and Swamee-Jain above 4,000. The latter relation is documented in [EPA EPANET 2.2 section 12](https://usepa.github.io/EPANET2.2/12_analysis_algorithms.html). The project blend is not EPANET's transition interpolation. Implicit Colebrook factors are separately bisected for turbulent points and retained as empirical-correlation comparisons, not an alternative numerical acceptance tolerance. Regeneration should produce an identical file.

## Liquid compression references

Retrieved 2026-09-15 from NIST Chemistry WebBook thermophysical fluid data (not generated by the production PR implementation).

- n-butane: CAS 106-97-8, query ID `C106978`.
- n-pentane: CAS 109-66-0, query ID `C109660`.
- n-decane: CAS 124-18-5, query ID `C124185`.

Query template (substitute the compound ID):

`https://webbook.nist.gov/cgi/fluid.cgi?ID=C106978&Action=Data&Type=IsoTherm&Digits=10&PLow=900&PHigh=1100&PInc=100&T=300&RefState=DEF&TUnit=K&PUnit=kPa&DUnit=mol%2Fl&HUnit=kJ%2Fmol&WUnit=m%2Fs&VisUnit=uPa*s&STUnit=N%2Fm`

Raw TSV headers preserve units. Volume is L/mol and pressure kPa; convert to m³/mol and Pa before differencing. The 1 MPa point calibrates a constant volume translation; the 0.9 and 1.1 MPa points independently constrain the pressure slope. This narrow three-point check is a necessary screening test, not qualification of a broad domain. NIST energy reference values are not directly compared with the repository's sensible-enthalpy datum.

The synthetic ideal-gas Cp polynomial used in the unit model is only for derivative/identity testing and does not supply the NIST volume/compression oracle. The PR critical constants and acentric factors are specified explicitly in each fixture; changing them requires new fixture provenance and qualification.
