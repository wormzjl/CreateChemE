- `holdup-prototype-be-fast.patch` (2026-09-26, runs 91-99; thirteen tracked files: the nine of the be patch plus `thermo/FluidThermodynamics`, `thermo/HydrocarbonModel`, `thermo/TranslatedPengRobinson`, `thermo/GlobalLiquidResponse`): the be patch plus the cost-per-solve levers and the memory work of review 8.7. Apply it to a clean 9674bf1 **instead of** the other patches (it contains them; `git apply --check --reverse` on the patched tree and `--check` on the restored base verified 2026-09-26). Every default reproduces the be patch (run 99d: 399/399 at defaults, no init script). On top of be it adds:
  - `junction.predictor` (`-Ppredictor=linear`, default `none`): a backward-Euler step whose input states are the ones the last accepted step ended at (same node ids and pipe identities; P, T and mass equal) starts pass 0's Newton from `x_seed + (dt/h_prev)(encode(s_n) - encode(s_n-1))` per node block, both states encoded with the pass's own layout; a node whose two states differ in phase regime or fail to encode keeps its seed; an amount unknown keeps its seed where the extrapolation leaves [0.5, 2] of it. Flows keep their warm start. `PassiveIntervalSolver` hands the start states and the step to `markBackwardEulerAccepted(graph, startStates, step)`.
  - `junction.jacobianReuse` (`-PjacobianReuse=on`, default `off`): a non-rate solve opens on `structures.get(structure)` (the structure's latest workspace, whatever dt built it) instead of the dt-keyed `workspaces` entry. `junction.reuseTrace` (`-PreuseTrace=true`, diagnostics on) prints one `REUSETRACE` line per pass.
  - `junction.rowForm` (`-ProwForm=amount`, default `rate`): an owned junction's mixing and enthalpy rows of a step solve (not a rate solve) are multiplied by `dt/m_J`; the flux-form weight becomes `(m_J/dt + Q) dt/m_J`.
  - `junction.newtonTolerance` (`-PnewtonTolerance=1e-8`, default `1e-9`): the FULL path's Newton tolerance (small-headspace 1e-10 and APPROXIMATE 1e-6 unchanged); the FULL equation gate becomes `max(1e-8, tolerance)`, so it moves only above 1e-8.
  - `junction.phaseCheck` (`-PphaseCheck=once`, default `both`): the converged Newton point is not phase-checked (no `phaseCorrection` flash before the reconstruction); the reconstructed point still is.
  - `junction.lowAlloc` (`-PlowAlloc=on`, default `off`; arithmetic unchanged: runs 96/97 equal the base on every probe line, suite run 99c equals 99a on every message): the flash's equilibrium iteration writes ln phi into two buffers (`HydrocarbonModel.logFugacityInto`, `TranslatedPengRobinson.evaluateValues`, `GlobalLiquidResponse.logFugacityInto`) instead of building two phase records per iteration; a phase-check flash at a node's prepared temperature reuses that node's Peng-Robinson workspace (`FluidThermodynamics.flashTP(..., Prepared)`); `HydrocarbonModel.phase` copies only the coefficients its record keeps; `PipeTransfer.sample` shares one empty stream per basis size; the retained last solve drops its per-node decode cache after the step (`Equations.releaseDecodeCache`); the interval solver drops its cold-start graphs after the first accepted step.
  - Diagnostics (count only, while `SolverDiagnostics.ENABLED`): flashes by site (`FLASH_NEWTON`, `FLASH_RECONSTRUCTED`, `FLASH_FAILED`, `FLASH_TRACE_SEED`) and their nanoseconds; cold-seed and cold-rate-solve nanoseconds; predictor applications; thread-allocated bytes of the Newton, the Jacobian build (`SparseNewton.JACOBIAN_ALLOC/NANOS`), the reconstruction, `checkConservation` and the phase checks. The ThreadMXBean reads themselves allocate, about 1 % of the probe total (JFR run 91k).
- Probe additions (2026-09-26, runs 91+): `-PjunctionInterval=<s>` (`junction.interval`, default 0.1) cuts the transient probe's schedule (10 s rest, 3 s injection, 3 s settle) into intervals of that length, a segment's last interval shortened to its end (5 s: 5, 5, 3, 3); at 0.1 the probe is line for line the old one (run 91a = run 87b). `-PstartStep=hint` (`junction.startStep`) starts each interval at the previous interval's `nextStepEstimate()` (0.05 s cold), as `RetainedSolver` does; default `initial` (`Settings.initialStep` 1 s, capped by the interval). Off the 0.1 s interval every interval end prints a `HOLDUP_TRAJECTORY` line. `HOLDUP_COST` gains the reuse, evaluation and property counters and the prototype counters above (`JunctionHoldupStaticProbe.PROTOTYPE_COUNTERS`). The probes as they were for runs 1-90 are kept as `*.java.runs1-90.txt`.
