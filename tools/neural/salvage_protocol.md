# Original-matrix Transformer salvage, revision 1

The registered population is the retained Gen2 admitted matrix: 2,793 unique canonical inputs (1,993 TRAIN, 405 validation, 395 test), from 2,809 candidates with 16 preflight exclusions. The original fold assignment is immutable. The 35 historical challenge rows are not members of this matrix and are not swept.

The frozen Transformer has SHA-256 `7aa7eaa5ecbe4cea51a31bbe4724569e40900b128e98b1d69a6068e5e7d43e5e`. Each admitted condition receives one LNN_FIRST request, with ten owned platform workers, ten maximum in-flight requests, a 30-second request deadline, a 2-second neural budget, and 16 neural iterations. Each request can use native fallback according to the existing LNN_FIRST implementation. There is no outcome-based retry, threshold change, extra strategy, or solver warmup on matrix conditions.

`salvage_src/V3SalvageNplus1Probe.java` copies the frozen concurrent evaluator's native `run` and deadline/measurement helpers verbatim. Registration asserts those source blocks match. `V3BoundedEvaluation` owns worker admission, result publication, cancellation, and bounded shutdown; only the caller writes and flushes completed journal rows. Runtime scheduling metadata records actual active/in-flight/thread counts and termination. This is label acquisition under concurrent load, not a serial performance benchmark.

The exact N set is the 805 strictly qualified eligible TRAIN records in frozen Transformer data-v2. Their existing records and provenance are preserved. New labels must pass `prepare_transformer_data.strict`, including same canonical input as the accepted native seed, water equilibrium qualification, all acceptance checks, final Newton evidence, 1e-8 closure/flow limits, 1e-12 backward error, and temperature-step evidence. Advisories are excluded.

Only canonical TRAIN inputs absent from N can be appended. Validation/test outcomes are audit-only. A new label is quarantined if it differs materially from an existing strict profile or its earlier provenance already reports material root disagreement. Existing N labels are never replaced. Material means maximum temperature difference over 0.1 K, component/free-water flow difference over 1e-4 of feed, any wet-mask difference, or any condenser-branch difference.

Registration, immutable copied model/matrix/N, source/code hashes, and native helper identity checks are in `build/neural-salvage/nplus1-v1/plan.json`. The registration archive is outside Gradle clean at `.neural-cache/salvage-nplus1-v1/registration.zip`. Complete newline-delimited journal rows are periodically copied into distinct immutable `checkpoint-NNNN.zip` archives. A verified execution failure would require a separately preserved recovery registration over only uncompleted IDs; native failure outcomes are not retry candidates.
